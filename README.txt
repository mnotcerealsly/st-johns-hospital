배포
1. 새 GitHub 저장소에서 GitHub Pages를 main / (root)로 설정합니다.
2. 이 ZIP의 index.html을 저장소 최상위에 올리세요.
3. 추후 블레이크 사진이 확정되면 blake-portrait.webp 라는 파일명으로 index.html과 같은 위치에 올리세요.
   사진이 아직 없어도 사이트는 정상 동작하며, 큰 흰 사진 칸에 임시 안내가 표시됩니다.
4. index.html 내부에 CSS, JavaScript, 입체형 픽셀 아이콘 이미지가 포함되어 있어 별도의 라이브러리나 서버는 필요 없습니다.

화면 구성
- 바탕화면: My Computer / Patient Records / Internet Explorer / Recycle Bin
- 하단: Start, 실행 중 창 버튼, 시간
- Patient Records: 가운데 대형 사진 영역, 하단 고정 환자 정보, 의사 대담은 Session Notes
- Internet Explorer: 성 요한 정신병원 소개 페이지 (임시 문안)

유의
- 거위 이야기는 아직 원고가 제공되지 않아 임시 텍스트만 있습니다.
- 사진 교체 시 기존 blake-portrait.webp를 같은 이름으로 덮어쓰면 됩니다.
- 병원 관련 내용은 가상 설정이며 미확정 정보는 임의 확정하지 않았습니다.
